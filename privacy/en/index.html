Stimmivo · Privacy

Your voice stays with you.

Last updated: 25 August 2026 · Applies to Stimmivo 1.0

1. Controller and contact

AppsMakerDeluxe
appsmakerdeluxe@gmail.com

2. Local processing

Stimmivo processes audio only when you deliberately share it with the app through Android or select it in the system document picker. Speech recognition runs using a local model on your device. Audio and transcripts are not sent to AppsMakerDeluxe.

3. Model delivery and network

Stimmivo can download a speech model through Google Play. Google Play processes technical connection and device data under its own terms. Once installed, transcription itself does not require a network connection.

4. History and deletion

Stimmivo can save transcripts in a local history. History is enabled by default and deleted after seven days; you can turn it off or choose another retention period. Only text, time, duration, language and source category are stored. Original audio is not copied permanently. You can delete entries at any time.

5. Auto-transcription beta

If you enable the optional beta mode, Stimmivo receives access to Android notifications for the diagnostics you set up. It processes a message automatically only when its audio is technically and lawfully accessible. Availability can vary by messenger and device.

6. Permissions and security

Stimmivo does not request contacts, microphone or broad storage access. Notification access is used only after your approval. Temporary work files are removed after processing. Release logs do not contain audio or transcript content.

7. No ads, accounts or tracking

Stimmivo has no accounts, ads, analytics or tracking SDKs and does not sell data.

8. This website

This static website is hosted on GitHub Pages. AppsMakerDeluxe sets no cookies, trackers, analytics or advertising scripts. GitHub may process technical server data such as IP address when the site is requested. See the GitHub Privacy Statement.

9. Questions

For privacy questions, contact appsmakerdeluxe@gmail.com.
