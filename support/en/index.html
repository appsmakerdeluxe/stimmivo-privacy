Stimmivo · Help

Read voice messages.

Share audio

Press and hold a voice message in a compatible messenger, choose Share, then choose Stimmivo. The audio is processed locally.

Choose a file

Open Stimmivo and tap “Choose audio”. Android’s document picker gives Stimmivo access only to the file you select.

Speech model

On first use, install a local speech model after consent. Transcription works offline once it is installed.

Auto-transcription beta

The beta mode gives an honest compatibility diagnosis for each messenger. If audio is inaccessible, sharing remains the reliable method.
